# GitWise roadmap

## Milestone 0 — Foundation
- [x] Establish repository structure and Python API.
- [x] Add health endpoint and starter tests.
- [ ] Add CI, formatting, and type checks.
- [ ] Define repository identity and Software Genome schemas.

## Milestone 1 — Repository intelligence
- [ ] GitHub App authentication and installation flow.
- [ ] Public repository URL onboarding.
- [ ] Bounded, read-only repository tree ingestion.
- [ ] Detect languages, frameworks, manifests, and key documentation.
- [ ] Generate an evidence-backed repository snapshot.

## Milestone 2 — Architecture and memory
- [ ] Build module and dependency maps.
- [ ] Capture project conventions and architectural decisions.
- [ ] Track snapshot changes by commit.

## Milestone 3 — Guardian
- [ ] Surface dependency and maintenance risks.
- [ ] Add explainable findings with source evidence.
- [ ] Integrate opt-in pull request intelligence.

## Milestone 4 — Controlled agents
- [ ] Define narrow agent capabilities and permission boundaries.
- [ ] Require human approval for repository writes.
- [ ] Record agent actions and outcomes for auditability.
